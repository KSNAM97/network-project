# 장비 포트 매핑표 (GNS3 장비명 기준)

`docs/network-project-final.md` 4절의 링크 정보를 GNS3 장비명 기준으로 한 줄에 한 링크씩 풀어 쓴 표입니다. 케이블링과 컨피그 작성의 기준으로 사용합니다.

- 장비명은 GNS3에 입력한 이름이고, 인터페이스 이름은 라우터 `GiX/Y`, Cisco 스위치 `eX/Y`, Arista cEOS 스위치 `EtX`입니다.
- 포트와 서브넷은 설계 단계의 **제안값**입니다. GNS3에서 실제로 선을 연결한 뒤 이 표와 대조하고, 다르면 이 표를 고칩니다.
- `제안값`: 설계 문서에 없어서 같은 패턴으로 채운 값입니다. `미정`: 아직 정해지지 않은 값입니다.
- 서브넷이 `-`인 링크는 L2 링크(트렁크, EtherChannel, access)입니다.
- ISP-1과 ISP-2는 같은 구조이고 `100.1.x.x`, `100.2.x.x`로 구분합니다. 번호 `#`는 이 문서 안의 링크 번호입니다.

## 3. 미확정 항목

- DC 서버 스위치(`DC-SW1-L2`, `DC-SW2-L2`)의 업링크 포트(`Et1`, `Et2`)와 BR1·BR2 스위치 간 트렁크 포트(`e2/0`, `e0/0`, `e0/1`)는 설계 문서에 없어 제안한 값입니다.
- BR1·BR2 스위치↔라우터 L3 링크 4개의 서브넷이 정해지지 않았습니다. HQ 패턴(`10.1.0.0/30`, `.4`, `.8`, `.12`)대로 `10.3.0.0/30` ~ `10.3.0.12/30`, `10.4.0.0/30` ~ `10.4.0.12/30`을 쓸지 정해야 합니다.
- DNS1, DB1, 사이트별 호스트(H1, H2, HQ 호스트)는 GNS3에 노드가 없어 서버·호스트 쪽 포트가 `미정`입니다.
- HQ 호스트가 `HQ-SW-1`의 어느 포트에 연결되는지 설계 문서에 없습니다(HQ-SW-1은 `e1/0` ~ `e1/3`만 사용 중).
- 라우터 슬롯/어댑터 수: `PrivI-net`이 5포트(`Gi0/0` ~ `Gi4/0`), `HQ-R2`와 `BR1-R1`, `BR2-R2`가 5포트를 씁니다. GNS3에서 7200 어댑터가 이만큼 있는지 확인해야 합니다.
